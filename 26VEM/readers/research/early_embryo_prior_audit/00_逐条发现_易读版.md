# 34条发现：逐条说清楚

先看原研究说了什么、官方数据看到什么，再看能否得出一致结论。E是采样日龄，Et是作者模型估计的时间。外部图谱的比例先按每个混合样本计算，再对样本取平均。

## D008 E6.75→E7.25：原条细胞占比上升，两边方向一致

**原研究 / 外部数据：**从E6.75到E7.25，外部图谱中原条细胞的平均占比为15.71% → 17.17%。两个阶段分别有1个和3个混合样本。

**官方数据：**官方同名类别的占比为2.88% → 5.15%；对应细胞数为204/7,093和685/13,295。

**现在能得出的结论：**两份数据中，这类细胞所占比例都上升，但占比的绝对水平和变化幅度不同。这只能支持方向一致，不能证明细胞分化更快，也不能说明两个样本覆盖了完全相同的组织。

来源：[2019年小鼠胚胎图谱（本次计算）](https://www.ebi.ac.uk/biostudies/arrayexpress/studies/E-MTAB-6967)。 [打开详细记录](knowledge.html#claim=D008)

## D010 E6.75→E7.25：胚外外胚层细胞占比下降，两边方向一致

**原研究 / 外部数据：**从E6.75到E7.25，外部图谱中胚外外胚层细胞的平均占比为19.42% → 12.16%。两个阶段分别有1个和3个混合样本。

**官方数据：**官方同名类别的占比为5.88% → 2.22%；对应细胞数为417/7,093和295/13,295。

**现在能得出的结论：**两份数据中，这类细胞所占比例都下降，但占比的绝对水平和变化幅度不同。这只能支持方向一致，不能证明细胞分化更快，也不能说明两个样本覆盖了完全相同的组织。

来源：[2019年小鼠胚胎图谱（本次计算）](https://www.ebi.ac.uk/biostudies/arrayexpress/studies/E-MTAB-6967)。 [打开详细记录](knowledge.html#claim=D010)

## D011 官方胚外内胚层占比下降；外部样本的变化方向不一致

**原研究 / 外部数据：**外部E6.75样本的占比是9.49%；E7.25三个样本分别是7.69%、9.70%、10.10%。与早期样本相比，有的较低、有的较高。平均值9.49%→9.16%掩盖了这种差别。

**官方数据：**官方同名类别的占比为24.36% → 14.60%；对应细胞数为1,728/7,093和1,941/13,295。

**现在能得出的结论：**官方下降很明显，但外部样本没有给出一致方向。因此不能把“胚外内胚层占比下降”当作本次已稳定复现的规律。

来源：[2019年小鼠胚胎图谱（本次计算）](https://www.ebi.ac.uk/biostudies/arrayexpress/studies/E-MTAB-6967)。 [打开详细记录](knowledge.html#claim=D011)

## D007 官方尿囊细胞占比上升；外部这两期没有同名细胞可供核对

**原研究 / 外部数据：**外部E6.75的1个样本和E7.25的3个样本都没有数到标为Allantois（尿囊）的细胞。因此这里的0%→0%不能解释为尿囊细胞比例保持不变。

**官方数据：**官方同名类别的占比为2.40% → 4.42%；对应细胞数为170/7,093和587/13,295。

**现在能得出的结论：**没有足够的外部同名细胞，无法核对官方的上升趋势；也不能说这些胚胎没有尿囊。

来源：[2019年小鼠胚胎图谱（本次计算）](https://www.ebi.ac.uk/biostudies/arrayexpress/studies/E-MTAB-6967)。 [打开详细记录](knowledge.html#claim=D007)

## D009 官方尾侧上胚层占比4.47%→8.74%；外部同名细胞太少

**原研究 / 外部数据：**外部E6.75没有数到同名细胞；E7.25三个样本分别只有0、3、5个，样本平均占比约0.04%。

## D012 官方血液祖细胞占比0.86%→1.32%；外部证据不足

**原研究 / 外部数据：**外部E6.75没有数到同名细胞；E7.25三个样本分别有0、32、31个。虽然平均占比变为0.34%，但部分样本没有这类细胞。

**官方数据：**官方同名类别的占比为0.86% → 1.32%；对应细胞数为61/7,093和176/13,295。

**现在能得出的结论：**可以报告观测比例变大，但外部各样本不足以支持可靠的方向核对；不能把未数到细胞当作它们尚未产生。

来源：[2019年小鼠胚胎图谱（本次计算）](https://www.ebi.ac.uk/biostudies/arrayexpress/studies/E-MTAB-6967)。 [打开详细记录](knowledge.html#claim=D012)

## L001 E6.5 到 E8.5，多能上胚层细胞的占比总体下降

**原研究 / 外部数据：**2019年的小鼠胚胎图谱发现，随着发育推进，仍保持多能状态的上胚层细胞所占比例总体变小。原文没有说每两个相邻阶段都必然下降。

**官方数据：**官方把上胚层分为“前侧”和“尾侧”等类别，没有明确标出与论文同定义的“多能上胚层”。

**现在能得出的结论：**目前不能直接核对这个趋势：需要先确认两份数据究竟把哪些细胞算作多能上胚层。

来源：[Pijuan-Sala等，2019年论文](https://pmc.ncbi.nlm.nih.gov/articles/PMC6522369/)。 [打开详细记录](knowledge.html#claim=L001)

## L002 E6.75 的胚胎中，论文已经观察到中胚层细胞

**原研究 / 外部数据：**2019年的图谱在E6.75样本中已经识别出中胚层细胞。这说明该阶段能观察到它们，不代表它们恰好在这一天首次产生。

**官方数据：**官方E6.75有多个可能相关的细胞类别，但若干缩写和分类边界尚未查清，不能直接把它们合并成论文的中胚层类别。

**现在能得出的结论：**需要补齐官方类别定义，才能回答“官方是否也看到了论文所指的中胚层”。

来源：[Pijuan-Sala等，2019年论文](https://pmc.ncbi.nlm.nih.gov/articles/PMC6522369/)。 [打开详细记录](knowledge.html#claim=L002)

## L003 E6.75 的胚胎中，论文已经观察到定型内胚层细胞
