# 输入语义、限定范围与已知差异

2026-11-16，Asia/Shanghai。这里补充原始输出的字段语义；冻结CSV/JSON保持原哈希，明确分层的二次导出在`supplement/`。

## 计数与表示

- 官方E6.75/E7.25/E7.5的layers/counts为非负整数；X与log1p(counts/每行总量×10000)一致到约5.5e-7。
- E8.0的13,573个非整数值占2,112,484个非零项约0.643%，均是半整数。未核实小数的形成步骤，不四舍五入，也不解释为分子数。官方标志统计直接用发布native X；跨来源共同基因重标度只作released_weight_sensitivity。
- 官方标志表的mean_log基于各文件全部498/500列；跨来源mean_log基于496或450个共同基因。两种均值的归一化分母不同，不应混用数值。
- 共同表示的均值排除共同基因总量为0的行；检测率仍以全部组内观测为分母。零总量数量及eligible标记见每个来源的profile_groups.csv。
- E-MTAB使用原始整数MTX；同symbol多个feature隔离，不进行歧义别名合并。旧early.h5ad已经log-normalized，未将它再次当作count归一化。
- GSE278603 rep1用layers/counts、var；rep2用raw/X、raw/var。两者整数校验通过，但观测单位是重建对象，不能写成未经证明的细胞数。

## 原始输出字段补充

| 文件或字段 | 限定说明 |
|---|---|
| results/*pair_definition.json 的representation | 通用模板写counts；其中E8.0实际是发布权重敏感性，不能当作已核实整数计数 |
| results/type_specificity.csv、stage_change_comparison.csv | 原表未携带tier；E8.0相关行全部为敏感性。带列版本见supplement同名文件 |
| results/official_marker_profiles.csv | E8.0均值来自native X，其余来自全部面板counts归一化；带逐行说明版本见supplement同名文件 |
| results/FREEZE.json 的frozen_before_official_expression | 34条知识在run01官方表达前首次冻结；run02逐字节复用。v3数据语义修订发生在run01失败后，不是整个协议全程盲法 |
| native_observation_summary 的measured_genes | E-MTAB的29,452为原始feature行数；唯一symbol精确匹配是另一个集合 |
| 所有“检测率” | 相应表达层>0的比例；不等于真实RNA存在概率或实验检出敏感度 |
| 所有label/group | label保留原名，group只作固定名称对应；未映射仍在分母中，缺标签不等于类型不存在 |

各原标签少于30个观测时标为小样本，计数仍完整保留；逐样本标记见[supplement/composition_with_small_group_flags.csv](supplement/composition_with_small_group_flags.csv)。

## QC敏感性

当前协议称去掉少于5个unique genes的观测，发布E6.75/E7.25却仍有448/749行低于门槛；这些行均属于Unknown。全体观测为主分母，另表去掉这些行之后，Unknown占比分别下降5.534/5.234个百分点。原条与EXE-Ectoderm的方向一致结论不改变。没有为使文件符合网页而覆盖原矩阵。

## GSE169210准入

本地WT BL6/ICR元数据包含cell_id、plate、embryo_id、developmental_time、metacell_id及条码；没有可直接用作实测采集E日和统一celltype的字段。原文明确Et为作者推断时间；plate不是胚胎。元数据表头和SHA在[evidence/count_semantics_inspection.json](evidence/count_semantics_inspection.json)。未把模型Et四舍五入成E日以绕过保护区间，也没有把干预与WT混在数值比较中。

本轮原文知识可引用这些研究，但只有E-MTAB允许实测阶段与GSE278603的E8.0进入数值比较。规则原文见[当前规则快照](provenance/snapshots/official_live_rules.txt)。
