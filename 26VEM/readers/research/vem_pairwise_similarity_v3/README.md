# 官方与外部数据逐对比较

已完成 **24个配对**：8份官方文件与12个外部数据对象，涉及12个VED编号。其中两个编号共用一份E9.5计数/注释组合，不能按12项独立研究理解。共63项有数值的整体或细胞类型比较，19项缺对应标签。

主排序有 **27项**，其中 **11项表达排序相关≥0.8**。高相关仅指这些细胞类型、基因集和表示下的高低顺序接近，不表示取材比例、检出率和整个数据集相同。
最能说明差别的是：T1 E8.5 与 **VED-004 · TOME E8.5 全胚胎图谱** 的轴旁中胚层相关0.921，但前100高表达基因只重合11个；T1 E9.5 与 **VED-012 · Feng 分心腔单细胞图谱** 的心室心肌相关0.920，前100重合85个。因此本报告先列“表达排序相关较高”，再逐项核对，不把它概括为整个数据都很相似。

## 范围与限制

- 官方共223,187个观测；外部缓存共456,207个允许观测。缓存含配对阶段之外的允许行，这两个总数不是参加每一项比较的样本数。逐条实际人数另列。观察数不是胚胎数。
- 同阶段结果、相差0.25天结果、空间bin、富集谱系和旧QC敏感性分开。T3缺少规则允许且基因型一致的来源；不拿其他KO代替。官方验证阶段没有同阶段、允许使用的外部答案，不为凑配对越过保护窗口。
- 原始标签和未映射对象保留。完整全胚、心脏周边、分心腔、FACS富集与空间bin的比例分母不能互换。
- VED-004 · TOME E8.5 全胚胎图谱的12个RT组未核实为独立胚胎；VED-012 · Feng 分心腔单细胞图谱的心腔样本也不冒充独立胚胎；官方没有生物个体字段。
- 共同基因归一化表示相对表达。T1与VED-006 · de Soysa 早期心脏图谱逆log恢复的是相对表达质量；E8.0官方小数counts，以及VED-019 · Osr1 阳性第二心场单细胞数据整数样式未经完全核实的权重，都有明确标记。
- 所有“对应细胞”依赖现有注释；不能把注释表达特征的相符称为独立身份验证。来源差异不能直接拆成纯技术批次或真实生物差异。
