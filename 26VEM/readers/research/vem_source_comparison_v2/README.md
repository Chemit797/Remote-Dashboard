# 同任务的官方与外部数据：具体相似在哪里、差异在哪里

这项比较独立于先验核对：来源对、阶段、类型和数学模型在看本轮统计前固定。整体上，E9.5 T1核RNA与两份外部心脏图谱有较高表达相关；早期胚胎及心脏空间面板的相关较弱。共同的器官表达特征与明显的逐基因差异同时存在。现有结果不支持一个已验证、可稳定跨阶段使用的简单换算关系。

外部来源统一使用“编号 · 固定名称”；旧简称、登录号和内部代码可在[名称对照表](../../docs/EXTERNAL_DATASET_NAMES.md)查询。来源名称不随任务、阶段或重复号改变。

每个来源先按样本和作者类型计算，再对样本等权；每个类型至少30个观测才进入主比较。VED-007 · Qiu 产前细胞核图谱在允许阶段没有与官方成熟心室/心房类群同时满足定义及数量要求的组，因此`heart_QIU`为0；T1与VED-007 · Qiu 产前细胞核图谱实际仅能比较E9.5心内膜。VED-012 · Feng 分心腔单细胞图谱心房心肌只有11个细胞，未纳入强判断。原始计数及全部未映射标签仍保留在来源组成表，未因不匹配而从分母删除。

主比较精确匹配基因符号，歧义符号隔离。每个观测在共同基因内按总量归一化到10,000后取log1p，随后计算样本×类型均值。共同基因总量为零的观测不进入表达均值，数量另列；检测率始终以该组全部保留观测为分母。T1只有已发布logCP10k，逆变换得到的是相对表达质量，不是恢复的raw counts。

T2官方测量空间分割细胞；VED-020 · Stereo-seq 胚胎三维重建图谱测量空间重建对象；VED-009 · MOSTA 心脏空间图谱测量空间bin；VED-007 · Qiu 产前细胞核图谱测量细胞核；VED-012 · Feng 分心腔单细胞图谱测量解离细胞。它们的观测单位不同。不同任务使用自己的规则边界；没有把T2胚胎可用阶段借到心脏任务。T3没有满足目标扰动、Cre/等位基因、阶段及规则条件的外部数值配对，登记原因后停止，不以另一KO顶替。

## 4. 类型特异性和阶段变化

把每个基因在各类细胞间的平均水平去掉，再比较它更偏向哪类细胞，T1与VED-012 · Feng 分心腔单细胞图谱 E9.5的相关为0.560；两侧最高表达类型相同的基因为58.29%（16,487个在两侧均有唯一最高类型的基因）。这说明整体轮廓的0.859–0.918相关不能替代细胞类型特异性的检查。并列最高和两侧无变化的基因未计入最高类型一致率。

早期E6.75→E7.25，胚外外胚层、胚外内胚层和原条的表达变化相关分别仅0.054、0.085、0.066。原条观测比例确实同向上升：官方2.88%→5.15%，外部等权混样15.71%→17.17%；类型内部的逐基因变化却不因此一致。来源范围不同，绝对比例只能作为取材后观测的差别。

新的心脏来源对只有一个可用共同阶段，或第二阶段缺合格对应类群，无法评价阶段变化。所有未映射和小组见[mapping_coverage.csv](mapping_coverage.csv)及逐来源组成表。

早期计数主分析只有两个阶段，留一个阶段后无法保留两个训练阶段。留类群时仿射平均减少59.8%的误差，但打乱类型也减少59.0%；这种改善很大部分可以来自整体数值尺度，不能证明保留了可靠的细胞对应关系。Ridge在部分留出类群上明显恶化。

含E8.0发布权重的敏感性分析可做两种留出，但整阶段留出时仿射的打乱对照平均改善更高；Ridge仍失败。按冻结的“双重留出稳定改善且优于打乱对照”要求，没有模型通过。新心脏来源对的阶段/类型数量不足，未用同一批数据内拟合得好代替泛化检验，也没有继续扫模型或参数。

## 6. 复现与边界

输入路径/哈希、源表示、样本、规则边界在[输入清单](../vem_prior_knowledge_v2/results/input_manifest.json)及[来源登记](../vem_prior_knowledge_v2/provenance/01_外部数据任务对应.md)。冻结比较在[方案](../vem_prior_knowledge_v2/test_plan.json)；[计算源码](../vem_prior_knowledge_v2/src/analyze_v2.py)与[独立复核源码](../vem_prior_knowledge_v2/src/verify_remote.py)均可复现。

当前比较能定位来源差异，不能分离技术平台、采样区域、个体和阶段定义各自的因果贡献。官方多数文件没有独立胚胎ID，因此没有用细胞数量产生跨胚胎P值。没有采用整合后混合程度证明相似。
